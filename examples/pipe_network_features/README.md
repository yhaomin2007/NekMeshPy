# Pipe-network mesh with small internal features

This extends the previous pipe network using NekMeshPy. Run from this directory:

```bash
python -m pip install numpy scipy
PYTHONPATH=vendor python build_network.py network.json
```

To rebuild, check corner-geometry overlaps, render the preview, and export the
obstacle visualization:

```bash
python -m pip install matplotlib
PYTHONPATH=vendor python preview_mesh.py
```

Both commands overwrite the generated files in output/. Python 3.9+ is required.
The bundled, unmodified nekmeshpy package is pinned to upstream commit
c81ff433e4be56df36904f7d5adee3da121340a3 of
https://github.com/yhaomin2007/NekMeshPy. An external checkout can replace vendor
in PYTHONPATH. The upstream repository was not modified or pushed.

## Geometry

The original 100 mm inlet tee feeds a main outlet expanding to 120 mm and a
branch contracting to 60 mm. Both outlets include 90-degree bends in different
planes. All units in network.json are metres.

Two new features are specified under `features` in network.json:

1. Smooth inward wall bump on the negative-y wall of the vertical branch
   transition, centred at z = 0.24 m. Its axial support is 120 mm and its design
   peak height is 5 mm. It vanishes smoothly at both axial ends and on the
   opposite pipe half. The deformation is applied to shared corner, edge,
   face and interior nodes, preserving the mesh's conformity. The represented
   geometry is a polynomial approximation of the design map.
2. Wall-attached partial baffle in the main outlet's straight tail, at
   y = 0.29 to 0.33 m (40 mm thickness), on the positive-x side of a pipe centred
   at x = 0.65 m. Whole mesh cells are excluded from the fluid domain, and all
   newly exposed faces receive a no-slip `baffle` boundary condition. The
   resulting solid rib blocks approximately 25.19% of the 120 mm bore area.
   This is a mesh-aligned stepped rib, not an exact straight-edged CAD plate.
   Selection uses a cross-section centroid threshold, so changing resolution
   can change the achieved blockage. Thickness is snapped to axial layers.

The tee and network layout remain template-based. No CAD Boolean or automatic
arbitrary-geometry decomposition is performed. `features.py` contains the two
new mesh operations. Feature locations and sizes can be edited in network.json
within the geometric constraints checked by the script.

## Files

- output/pipe_network.vtu: full high-order FLUID mesh; open in ParaView.
- output/baffle_obstacle.vtu: optional visualization of the excluded obstacle
  volume, generated by preview_mesh.py. It is not a CHT solid region or a second
  solver mesh. Load together with the fluid mesh to inspect the baffle.
- output/pipe_network.re2: corner geometry and Nek boundary conditions.
- output/pipe_network0.f00001: high-order coordinate-only Nek field file (X).
- output/features_preview.png: translucent overview and actual mesh sections.
- output/checks.json: dimensions, blockage estimate, quality and topology checks.
- output/quality_report.txt: repository mesh report.

Boundary IDs: wall=1, inlet=2, main_outlet=3, branch_outlet=4,
wall_bump=5, baffle=6. Wall, bump and baffle all have W no-slip codes; inlet
has v and outlets O. Actual velocity values and simulation settings are not
included. Colored feature groups are useful for inspection and later BC edits.

The `.re2` writer exports corners only, without curved-side records. Its wall
bump and elbows are therefore represented by the corner-defined map unless
high-order coordinates are loaded or reconstructed in the solver. The `.fld`
contains coordinates, not an initial velocity/pressure solution. Solver-specific
coordinate loading is required; no NekRS/Nek5000 run was performed.

## Validation of the included result

The new cross-section and axial resolution is higher than the original demo:
8 half-ring elements, 4 radial layers, target axial length 20 mm, geometry
polynomial order 3. Forty-four cells were excluded to form the baffle, leaving
7,956 fluid hexahedra and 9,009 corner points. Nine construction blocks are
joined before adding the features.

Checks passed: one connected component; watertight capped domain boundary;
conformal connectivity; no hanging points, nonmanifold faces, unnamed exterior
faces or incorrectly tagged interior faces. Minimum sampled scaled Jacobian
is approximately 0.469676. Both curved and corner-only maps have no inverted
elements at sampling orders 3, 5 and 7. Exported `.re2` was reread and checked
for element count, conformity and watertightness. The included preview run
also passed the repository's corner-geometry overlap search.

Sampling and corner-geometry overlap tests do not certify intersection-freedom
of full curved maps. The mesh demonstrates geometric feasibility, not flow
accuracy: thin baffle-edge shear layers and wakes would need dedicated
refinement for a CFD study. No wall thickness or heat-conducting solid is solved.
